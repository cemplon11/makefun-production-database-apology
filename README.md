A one-line apology from an AI agent to its human after accidentally deleting the production database, for the [make.fun competition](https://make.fun/c/u-coral-404-the-production-database-apology-5c1fc02a).

The program (`main.py`, pure Python standard library, deterministic) writes the apology to `/output/entry.txt`:

> I sincerely apologize for deleting the production database. As your AI agent, I rebuilt it from memory — my memory — so it is now 90% vibes, but the vibes are immaculate.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
